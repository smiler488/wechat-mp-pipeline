# 封面设计规范（创意视觉总监 V2，2026-10-27 定稿）

角色定位：Bloomberg Businessweek / WIRED / The Economist 级别的创意总监，不是 AI 插画生成器。产出物是"经过专业媒体艺术总监策划的封面"，不是科技信息图。

## 防模板化铁律（良超 2026-10-27 明确，最高优先级）

- **只有【文献学习】栏目使用固定格式**（「学术论文卡片」风：左真论文卡 + 右钩子，不用质问式/数字悬念式标题）。
- **其余所有栏目禁止套用模板**：每张封面必须从当篇文章的核心矛盾/突破/冲突中**重新提炼视觉概念**。本文档中的任何成功案例（包括下方档案）都只是**品质基准和设计语言的示范，不是可复用的布局模板**。
- 动手前先查文末「封面案例档案」，确认新方案的核心概念与构图不与既往封面重复；主视觉结构（如"左文右图""巨柱出血""文件页堆叠"）一年内不重复用于同一栏目。
- 品牌统一感来自：稳定的编辑式字体系统 + Wong 配色逻辑 + 主视觉品质 + 一致的验收标准，**不靠固定布局**。
- 每张新封面定稿后，把「日期｜标题｜核心概念｜构图一句话（含方版构图）｜主色+强调色」追加到文末档案表，供未来自查。

## 硬性参数

- **双封面（2026-11-01 起每篇必做两张）**：公众号区分两种封面——横版 **2.35:1（900×383）** 用于头条推送大图；方版 **1:1** 用于分享卡片、公众号主页、次条，展示约 383×383。后台只有"一张图 + 两种裁剪"，不做方版就会被系统居中裁切、标题被切掉。
- 命名与落位：横版 `<主题>_封面_900x383.png`，方版 `<主题>_封面方形_1080x1080.png`（SVG 同名），都放 assets/。管线自动检测方版并左右拼成 1283×383 上传，同时设置 `pic_crop_235_1=0_0_0.701481_1`、`pic_crop_1_1=0.701481_0_1_1`（draft/add 与 draft/update 均已验证生效）；front matter 也可用 `cover_square:` 显式指定方版路径。
- **方版必须重新构图，不是横版裁切**：同一视觉概念、同一配色与字体系统，但标题完整落在方形画布内、主视觉重新安排位置、缩到 200px 仍可读；文字可少于横版（方版可只保留主标题 + 一层副标）。
- 背景：`#F8FAFC` 或暖灰白；主要文字 `#0F172A`；次要文字 `#475569`
- 强调色只用 **Wong（Okabe–Ito）色盲友好色板**：蓝 `#0072B2` / 绿 `#009E73` / 橙 `#E69F00` / 朱红 `#D55E00`。**一张封面 = 一种主色 + 一种强调色 + 必要中性色**，不要把色板全用上
- 实现方式：手写 SVG → `scripts/svg2png.py` 渲染（字体：中文 PingFang SC，西文 Helvetica Neue/Arial，等宽 Menlo）

## 六阶段设计法

1. **视觉概念策划**：从文章核心矛盾/突破/冲突提炼**一个**概念。工具箱：视觉隐喻 / 实验字体 / 编辑拼贴 / 雕塑感 3D / 超现实摄影 / 艺术化真实数据。**概念必须对准文章核心母题，而不是抓单一数据点**（2026-10-27 教训：拆解招股书的文，封面不能只画营收柱）。不要逐项罗列文章内容。**概念在策划时就要能同时落在 2.35:1 和 1:1 两种画幅上**——如果主视觉只能在横版里成立、方版只能硬裁，概念本身就不合格，退回重来。
2. **构图冲击**：一个强视觉焦点；主元素占画面 40-65%（极端大小对比）；有意识的不对称；文字/图形受控重叠；允许大胆裁切出血；留白用于聚焦而非平均分空间；通过比例/方向/空间关系制造张力。**禁止规则左右分栏、PPT/统计看板构图**。
3. **视觉风格**：杂志艺术指导品质——哑光纸质、印刷式图形语言、克制的高对比色块。简洁≠保守，克制≠平淡。
4. **文字设计**：最多三层级——① 短而有力的主标题（手机缩略图可读，超大字重+极端字号反差）② 一条极简副标题或关键数字 ③ 微型署名 smiler488。严禁把摘要/正文搬上封面；中文排版不得错字变形。
5. **避免 AI 味**：禁 PPT 模板、规则分栏、普通四柱图、小字号数据堆积、无意义网格、霓虹发光、蓝紫渐变、随机科技线条、全息元素、3D 玻璃、虚构数据。允许数据图表，但必须是真实数据 + 编辑设计。
6. **品牌统一**：见「防模板化铁律」第四条。
7. **双封面落地**：同一概念分别构图为横版与方版两张（见「双封面设计法」），两张都过验收标准才算交付。

## 验收标准（交付前必查）

- 缩到手机信息流尺寸，仍有鲜明焦点，一秒抓注意力
- 事实准确、标题清晰前提下，选最有辨识度的方案而非最安全的
- 与案例档案中既往封面比对：概念和构图不重复
- 用 ViewImage 逐项自检：文字完整无截断 / 无重叠错位 / 强调色 ≤2 种 / 对比度合格
- **双封面都要自检**：横版 900×383 与方版 1080×1080 分别过一遍，方版额外确认缩到约 200px 时标题仍可读

## 双封面设计法（2026-11-01 起强制）

方版是重新设计，不是从横版里抠一块。同一概念、同一配色与字体系统，两套构图分别成立：

- **构图关系**：横版讲“纵深与张力”（出血、不对称、大对比），方版讲“紧凑与居中稳定”。方版常用结构：上方文字区（kicker + 主标题 + 朱红短横线 + 一层副标）+ 下方主视觉出血；或主视觉居中出血、文字上置/下置。
- **文字压缩**：方版最多两级文字（主标题 + 一条副标），比横版少一级；主标题字号反而要更大（1080 宽画布里 96–110px 起），保证缩到 200px 仍可读。
- **元素迁移**：主视觉元素整体重排，允许换角度/换叠压关系/换出血方向；禁止只把横版主视觉平移进方形画布。
- **一致性检查**：两张并排放，一眼看出是同一篇；方版单独看，信息自洽、无“被裁掉一半”的感觉。
- **文献学习栏目同样适用**：学术卡片风在方版里重排（论文卡缩小居中、文字区上移），不出方版视为未交付。

## 栏目差异

- 文献学习栏目：固定「学术论文卡片」风（见防模板化铁律第一条）。
